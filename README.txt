VITALRUSH V8 — PWA

Cette version est une Progressive Web App.
Installation iPhone :
1. Héberger le dossier sur un site HTTPS.
2. Ouvrir l'URL avec Safari.
3. Partager → Ajouter à l'écran d'accueil.
4. L'app s'ouvre ensuite en mode application.

Le GPS nécessite l'autorisation de localisation.
Le mode hors connexion utilise un Service Worker.

Pour une publication réelle : hébergement HTTPS + domaine, puis éventuellement App Store/Google Play via une enveloppe native.
